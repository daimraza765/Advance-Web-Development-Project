# Mosque Space Booking System

A full-stack web application for managing mosque bookings and co-working spaces.

## Tech Stack
- **Backend**: Node.js, Express, MongoDB Atlas
- **Frontend**: React.js, Vite

## Setup & Run (Single Command)

1.  Open a terminal in the root directory `d:/mosque-booking-system/`
2.  Install dependencies for root, backend, and frontend:
    ```bash
    npm install
    npm run install-all
    ```
3.  Start both backend and frontend:
    ```bash
    npm run dev
    ```
    - backend runs on port 5000
    - frontend runs on port 5173 (or similar)

## Manual Setup (Alternative)

### Backend
1. Navigate to `backend`
2. `npm install`
3. `npm run dev`

### Frontend
1. Navigate to `frontend`
2. `npm install`
3. `npm run dev`

## Features
- User Authentication (Login/Signup)
- View available spaces
- Book spaces
- Admin dashboard to manage spaces
